Ticket entity đã có sẵn:

- qrCode: string
- isCheckedIn: boolean
- checkedInAt: Date
- status: ETicketStatus
- relations: booking, seat, showtime

Không sửa Ticket entity và không tạo migration cho Task này.

Hãy triển khai API:

POST /tickets/:qrCode/checkin

Phân quyền:

- Bắt buộc đăng nhập bằng JwtAuthGuard.
- Chỉ ADMIN hoặc STAFF được phép gọi.
- Dùng RolesGuard và `@Roles(EUserRole.ADMIN, EUserRole.STAFF)` theo convention hiện tại.

Controller gọi method mới trong TicketService, ví dụ:

checkInByQrCode(qrCode: string)

Logic service:

1. Chuẩn hóa mã bằng `qrCode.trim()`.
2. Tìm ticket theo qrCode.
3. Load các relation cần thiết để frontend hiển thị:
   - seat
   - showtime
   - showtime.movie
   - showtime.room
   - showtime.room.cinema
   - booking
4. Nếu không tìm thấy:
   - HTTP 404
   - code: `TICKET_NOT_FOUND`
5. Nếu ticket không có status ACTIVE:
   - HTTP 400
   - code: `TICKET_NOT_ACTIVE`
6. Nếu ticket đã có `isCheckedIn === true`:
   - HTTP 409 CONFLICT
   - code: `TICKET_ALREADY_CHECKED_IN`
7. Cập nhật:
   - isCheckedIn = true
   - checkedInAt = new Date()
8. Không tự động đổi ticket status thành USED vì yêu cầu hiện tại chỉ cập nhật cờ check-in.
9. Nên dùng conditional/atomic update với điều kiện `isCheckedIn = false` để tránh hai nhân viên quét cùng một vé đồng thời.
10. Trả về `ApiResponse<Ticket>` chứa ticket sau khi cập nhật và đầy đủ relations.

Response thành công dạng:

{
  "success": true,
  "message": "Soát vé thành công",
  "data": {
    "id": 1,
    "qrCode": "TKT-...",
    "isCheckedIn": true,
    "checkedInAt": "...",
    "status": "ACTIVE",
    "seat": {},
    "showtime": {},
    "booking": {}
  }
}

     - thời gian check-in

   - Dùng `getErrorMessage`.
   - Hiển thị lỗi dễ hiểu.
   - Giữ trang hoạt động để nhân viên có thể thử mã khác.
8. Camera scanner:
   - Dùng package `html5-qrcode`.
   - Dừng hoặc pause scanner sau khi đọc được một mã để tránh gọi API liên tục.
   - Cleanup camera khi component unmount.
   - Nếu camera bị từ chối quyền, nhập mã tay vẫn phải hoạt động.
9. Giao diện responsive, dùng Tailwind và các component/style hiện có.
